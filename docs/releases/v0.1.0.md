# GNSScope v0.1.0

This is the first public binary release of GNSScope, an offline GPS L1 C/A software receiver and GPUI analysis desktop application written in Rust.

## Included

- Streaming `Int8` and `Int16` interleaved IQ file processing
- PCPS acquisition and deterministic multi-channel DLL/Costas PLL tracking
- GPS NAV decoding, observables, continuous position/velocity/time output, Hatch smoothing, and Kalman candidates
- Channel admission, loss detection, reacquisition, and serial/parallel determinism coverage
- Editable receiver configuration, processing queue, SQLite run history, replayable plots, sky/C/N₀ diagnostics, and candidate comparison

## Important limitations

- GNSScope processes recorded IQ files only; live SDR input is not implemented.
- The receiver currently implements GPS L1 C/A only.
- The real CTTC and LabSat validation datasets are not included in the packages.
- The macOS applications are ad-hoc signed but not notarized. The Windows installer is not code-signed. The operating system may require explicit confirmation before first launch.
- Linux builds require a Vulkan-capable graphics stack and are built on Ubuntu 22.04 for glibc-based x86_64 distributions.

Measured receiver evidence and remaining accuracy limitations are documented in the [receiver readiness audit](https://github.com/Sereinme/GNSScope/blob/v0.1.0/docs/receiver-readiness-audit.md).
